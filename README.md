# 心里的那把椅子

你习惯照顾别人，还是内心更渴望被照顾？24道原创日常情境，6种结果。

这是用于自我观察和交流的娱乐测评，不是心理诊断或经信效度验证的量表。

## 体验

直接用浏览器打开 index.html，无需安装或注册。答案只存放在当前浏览器的 localStorage，不上传服务器。支持返回改题、刷新续答、重新测评以及生成结果 PNG。

## 构建与部署

运行 `npm run build` 校验脚本语法和题库结构，并复制唯一网页入口到 dist/。没有外部依赖。

GitHub Pages 使用 main 分支的工作流自动部署 dist/，不会发布开发说明、题库副本或其他文件。

修改题库时，请同步 index.html 中的内嵌数据与 questions.json。结果逻辑是确定性的，阈值为本产品叙事规则。

原创建站内容与插画。仓库不包含用户答题记录、凭据或营销素材。
